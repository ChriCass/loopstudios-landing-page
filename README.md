# Loop — Landing Page

A responsive landing page built with React, TypeScript, Vite, and Tailwind CSS.

## What's inside

- **Navbar** — top navigation with a mobile hamburger menu
- **Hero** — full-width hero section with background image
- **Content Text** — descriptive section with title and body copy
- **Our Creation** — grid of cards showcasing creations, with desktop and mobile images
- **Footer** — social links and site navigation

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS v4

## Getting started

```bash
npm install
npm run dev
```
